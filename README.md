# fake_news_detection
Machine learning model to detect fake news


balanceData.py --> Script to balance the datasets to get equal results

labelData.py --> To label the data into two categories- 1 for 'True' and 0 for 'False'

trainTestSplit.py --> split the combined labelled data into 80% training and 20% testing data, resulting in 4 csv files = x_test, x_train, y_test and y_train
